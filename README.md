---

## 🌟 Overview

**LlamaForge** is a private, local-first web and game application generator designed for indie developers and creators. Built to eliminate cloud subscriptions, token caps, and rate limits, LlamaForge connects directly to local LLMs via **Ollama** (`nova:latest`) to build responsive websites, custom login pages, and interactive browser games right on your machine.

---

## ✨ Key Features

* **100% Local & Private**: Runs entirely on your hardware with zero external API dependencies or cloud costs.
* **Point-and-Click Prompt Assembly**: Use guided **Feature Ideas** modals to quickly toggle common components like Search, Dark Mode, Filters, Toast Messages, and Auth.
* **Pre-Generation Theme Engine**: Choose your visual style (*Cyberpunk*, *Minimal*, *Fantasy*, *Retro Arcade*, *Cozy Pastel*) **before** generating code to guarantee brand alignment.
* **Granular Color Control**: Custom Primary and Secondary hex color pickers ensure your design system matches your vision on the first try.
* **Live Split-Pane Preview**: Watch the AI compile code in real time and test interactive HTML5 canvas games directly inside the app.
* **Instant HTML Export**: Download clean, self-contained `HTML`, `CSS`, and `JavaScript` files ready for deployment or hosting on itch.io.
